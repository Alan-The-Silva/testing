To find the HTTPS link for cloning your repository,

navigate to the main page of your repository on the GitHub website.

Follow these quick steps to get the link and clone your project:

  1. Copy the HTTPS Link on GitHub
  2. Open your repository on GitHub.
  3. Right above the list of project files,
    • click the green Code button.
    • In the dropdown menu that appears,
    • make sure the HTTPS tab is selected.
  4. Click the Copy icon (it looks like two overlapping squares)
  5. next to the web URL to copy it to your clipboard.
  6. The link will look like this: https://github.com.
